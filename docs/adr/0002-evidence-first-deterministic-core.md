# ADR 0002: 증거 우선의 결정론적 코어 사용

- 상태: 채택됨
- 날짜: 2026-08-14

이 상태와 아래 결정은 **2026-08-14 당시의 기록**이며 새 승인이나 현재 증거 충족 선언이 아니다.

<a id="context"></a>

## 배경

보안 발견 사항과 자동 대응은 설명 가능하고 재현 가능해야 한다.
LLM만으로 구현하면 비결정성과 근거 없는 주장이 유입된다.

<a id="decision"></a>

## 결정

자산과 관계를 타입이 지정된 증거로 표현한다. 발견 사항, 위험 요인, 경로, 영향 반경에는
결정론적 정책 규칙과 그래프 탐색을 사용한다. 이후 LLM으로 구조화된 증거를 요약할 수 있지만,
인용 근거가 없는 사실을 만들거나 작업을 승인하도록 허용하지 않는다.

<a id="consequences"></a>

## 결과

- 모델에 접근하지 않고도 단위 테스트로 보안 동작을 입증할 수 있다.
- UI의 모든 주장에 증거로 연결되는 딥 링크를 제공할 수 있다.
- 누락된 커넥터 데이터는 신뢰도 저하로 드러난다.
- 보안 판단의 기준 원천을 바꾸지 않고 LLM 통합을 추가할 수 있다.

## 현재 구현과의 관계(2026-09-15)

`@agent-sentinel/domain`, `@agent-sentinel/graph-engine`,
`@agent-sentinel/policy-engine`, `@agent-sentinel/behavior-engine`이 타입 검증과
결정론적 분석을 구현한다. Foundry의 선언된 구성, Agent 365 패키지 메타데이터,
Entra 인벤토리는 런타임 호출·개인별 사용 권한·악용 성공의 증거로 승격하지 않는다.
정확한 `RUNS_AS` 0개, 적격 런타임 증거 0개인 현재 상태에서 그래프나 시뮬레이션의
존재만으로 실환경 검증·개선 조치 성공을 주장할 수 없다. LLM은 계속 설명용 자문 경계에 있다.

당시의 테스트 가능성은 설계 결과이지 최신 후보 전체 테스트 통과나 사람의 승인 기록이 아니다.
검토 코드 `1129bbe8`과 배포 `7c1336bc`의 구분은 [현재 상태](../current-status.md),
엄격한 권위·스냅샷 계약은 [데이터 모델](../data-model.md)을 따른다.
