| KI-014 | Current Foundry agents lack Entra identity metadata        | Entra inventory is live, but no exact object/application/client ID is available on the six agents, so no `RUNS_AS` edge is emitted             | Configure an agent identity or expose an authoritative identity ID in Foundry metadata; do not infer correlation by display name                      |
| KI-015 | Only Viewer has completed live role validation             | Analyst, Approver, Administrator, and write-scope behavior are proven in tests but not yet with live assigned principals                       | Assign least-privilege test principals and run the token-driven capability validator for every role                                                   |
| KI-016 | Power Platform inventory is authorization-gated            | The official ResourceQuery connector is implemented, but Copilot Studio and Agent Builder inventory is absent from the live estate             | Approve tenant scope and assign Power Platform Reader or an approved least-privilege ResourceQuery read RBAC role; do not add a Graph app permission  |
| KI-017 | Agent 365 package inventory is authorization-gated         | The official Graph v1.0 list connector is implemented but disabled; no Agent 365 package inventory is present in the live estate               | Separately approve Microsoft Agent 365 licensing and tenant-admin `CopilotPackages.Read.All` application consent; keep all package writes disabled    |

Missing evidence is an expected state, not a healthy state. Do not close an
issue by replacing a failed live signal with mock data.
