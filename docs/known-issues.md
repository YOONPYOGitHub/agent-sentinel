| ------ | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |

| KI-007 | Private CI runner may be deallocated                         | Queued builds do not start until the VM runs                                                                                                    | Start the runner before builds or add approved scheduling                                                                                             |
| KI-008 | Runner identity has image-push permission only               | Automated infrastructure deployment and what-if fail                                                                                            | Grant separately reviewed deployment RBAC or retain manual deployment                                                                                 |
| KI-009 | Service Tree record has no valid IcM node                    | Microsoft Entra rejects API and SPA app registration attribution with `Service not found`                                                       | Provide two SFI trusted service-admin identities, complete required on-call contact profiles, onboard to IcM, and allow up to one day for propagation |
| KI-010 | Manifest adapter has no authenticated ingestion endpoint     | Manifests must be supplied inline or from an absolute local path by an operator                                                                 | Implement an authenticated ingestion API; unauthenticated ingestion will not be added                                                                 |
| KI-011 | Manifest claims are non-authoritative and capped             | Adapter evidence stays at confidence ≤ 0.7 and never overrides first-party connector data                                                       | Correlate manifest claims against a first-party connector or a runtime telemetry connector                                                            |
| KI-012 | Manifest runtime evidence is declaration-only                | `runtime_observed` claims are trusted declarations, not independently verified telemetry                                                        | Configure `azure-monitor-otel` and cross-check manifest runtime claims against collected spans                                                        |
| KI-013 | Behavior drift shows synthetic observations in mock mode     | Drift data in the Observability page and AgentDetail page is labeled `[SYNTHETIC]`; the deployment has no configured live telemetry             | Configure `azure-monitor-otel`; live mode will query real `ObservationWindow` objects without a mock fallback                                         |

Missing evidence is an expected state, not a healthy state. Do not close an
issue by replacing a failed live signal with mock data.
