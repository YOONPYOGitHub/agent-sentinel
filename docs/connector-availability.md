# 커넥터 가용성

상태 기준일: **2026-09-14**.

이 대장은 구현 상태와 실제 가용성을 구분합니다. 코드가 존재하거나
애플리케이션 권한이 할당되었다는 이유만으로 커넥터를 연결됨으로 설명하지 않습니다.

현재 참조 환경에는 커넥터 소스 플레인이 프로비전되어 있습니다. Agent 365는 배포되어 `ready + complete` 상태입니다. 패키지 308개가 에이전트 패키지 노드 302개, 확장 패키지 노드 6개, 소스에 연결된 실시간 증거 레코드 308개로 정규화됩니다. 다른 커넥터 관찰은 아래에 날짜와 범위가 한정된 증거로 유지합니다. Power Platform에는 지원되는 무인 권한 부여가 없고, 매니페스트 수집에는 쓰기/인증 게이트가 적용되며, 비즈니스 성과 소스에는 권위 있는 공급자가 없고, MCP 게이트웨이 텔레메트리는 공급자 계약이 선택되지 않았습니다.

이는 참조 환경에서 민감 정보를 제거한 관찰 결과이지 다른 테넌트에 그대로 적용할
기본값이 아닙니다. 커넥터의 준비 상태는 배포 이미지 동등성, 사용자 인증,
정확한 에이전트-ID 상관관계 또는 개선 조치 실행을 확립하지 않습니다.
2026-09-01 Entra 결과는 인벤토리만을 의미합니다.
정확한 식별자 일치 하나 없이는 `RUNS_AS` 간선이 존재하지 않습니다.

## 상태 정의

| 상태                         | 의미                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 연결됨                       | 한도가 있는 실제 읽기가 성공했으며 그 증거를 관리 영역 스냅샷에 합성할 수 있습니다.                           |
| 설정됨, 공급자에 의해 차단됨 | 코드, 자격 증명, 의도한 읽기 권한은 있지만 공급자가 요청을 거부하거나 처리할 수 없습니다.                     |
| 라이선스로 차단됨            | 테넌트가 필수 제품 라이선스를 받기 전까지 공급자 워크로드나 API를 사용할 수 없습니다.                         |
| 승인 필요                    | 새로운 권한, 역할, 자격 증명 또는 쓰기 경로 변경은 활성화 전에 명시적인 검토가 필요합니다.                    |
| 텔레메트리 불충분            | 소스를 조회할 수 있지만 측정된 샘플이 증거 임계값을 충족하지 못합니다.                                        |
| 구현됨, 활성화 게이트 적용   | 코드는 완성되었지만 배포된 안전 설정이 의도적으로 실제 수집을 막습니다.                                       |
| 미구현                       | 프로덕션 커넥터가 없습니다. 모의 또는 매니페스트 증거는 명시적으로 실제 데이터가 아닌 상태를 유지해야 합니다. |

설정된 Foundry 및 Entra 소스는 이제 한도가 있는 결정적 집계를 사용합니다.
소스 작업은 최대 4개가 동시에 실행되고, 전체 실행 시간 한도 하나가 적용되며,
호출자 취소는 대기 중인 작업을 중단합니다. 취소 결과를 반환하기 전에 이미 시작한
모든 공급자 실행이 끝날 때까지 기다립니다. 각 공급자의 기존 페이지, 레코드,
재시도, 바이트, 요청 시간 한도는 계속 적용됩니다. 런타임 Azure Monitor 읽기는
API 읽기와 예약 작업 모두에서 정확한 에이전트/소스 바인딩 전반에 동일한
한정 스케줄러를 사용합니다. 대상 에이전트는 최대 1,000개, 동시 읽기는 4개이며,
전체에 단일 60초 기한을 적용합니다. 작업은 한도 초과, 실패, 취소된 각 에이전트에
대해 저하 진단을 유지하며, 이미 시작한 공급자 작업이 끝날 때까지 예약 실행을
종료하지 않습니다.

소스별 데이터 상태는 연결 준비 상태와 다릅니다. `complete`는 한도가 있으며
비어 있지 않은 권위 있는 읽기를 뜻합니다. `partial`은 불완전한 측정 증거를,
`stale`은 최신성 임계값을 지난 증거를 보존합니다. `unsupported`는 설정된 소스가
요청한 증거를 제공할 수 없음을 뜻하고, `empty`는 공급자가 성공적으로 레코드 0개를
반환했음을 뜻합니다. `failed`는 읽기 또는 합성 실패이며, `cancelled`는 호출자나
전체 기한이 작업을 중단했음을 뜻합니다. 완전한 실제 포괄 범위는 `complete`만이
확립합니다. 모의, 합성, 누락, 미지원, 빈 증거는 이를 확립하지 못합니다.

저장된 Agent 365 상태는 현재 소스 바인딩 세대를 기준으로 조정합니다.
기존 소스 ID를 활성화하거나 비활성화하면 현재 활성화 상태가 오래된 측정 상태를
대체합니다. 제거된 소스 ID는 재할당하지 않고 오래된 진단으로 남깁니다.
준비 및 완료 상태는 보관된 증거가 정확한 저장 스냅샷 세대와 정규 증거 다이제스트에
바인딩된 경우에만 해당 증거를 승격합니다. 작업은 바인딩된 상태보다 먼저
최종 스냅샷을 저장하며, 상태 쓰기가 실패하면 발견 사항을 게시하기 전에 중단합니다.

<a id="tenant-transition-impact"></a>

## 테넌트 전환의 영향

- 대체 Managed Environment는 프로비전되어 있으며 활성 Azure, Foundry, Entra,
  Purview, Defender for Cloud Apps, Teams 카탈로그, 애플리케이션,
  텔레메트리 검증 경로를 호스팅합니다.
- 과거 테넌트는 폐기 예정이며 더 이상 활성화 대상이 아닙니다.
- 대체 Microsoft 365 E5 (no Teams) 및 Teams Enterprise 라이선스가 활성화되어 있습니다.
- M365 E5만으로 모든 커넥터의 가용성이 자동으로 입증되지는 않습니다.
  - Agent 365에는 Agent 365 제품 라이선스와 Graph 동의도 필요합니다.
  - Teams 카탈로그 읽기는 별도로 라이선스가 부여된 Teams Enterprise 백엔드를
    통해 연결되어 있습니다.
  - Defender for Cloud Apps는 프로비전된 Defender XDR 테넌트와 별도로 승인된
    애플리케이션 권한을 통해 연결되어 있습니다.
  - Power Platform 인벤토리에는 지원되는 무인 권한 부여 경로가 없습니다.
    라이선스만으로는 차단이 해제되지 않습니다.
- 정확한 요청, 테넌트, 구독, 지원 식별자는 이 저장소 문서가 아니라
  Git에서 제외된 로컬 인계 자료에 보관합니다.

<a id="activation-rules"></a>

## 활성화 규칙

1. 새 커넥터는 모두 기본적으로 비활성 상태를 유지합니다.
2. 문서화된 읽기 API와 최소 권한 애플리케이션 권한 또는 Azure RBAC만 사용합니다.
3. 모든 응답에서 테넌트, 구독, 환경, 소스 경계를 검증합니다.
4. 공급자 데이터 형식이 잘못되거나 잘린 경우 실패 시 차단합니다.
5. 공급자 실패를 유형화된 상태로 보존하고 모의 성공으로 대체하지 않습니다.
6. 권위 있는 API가 에이전트로 식별하지 않는 한 직접 클라우드 리소스는 제어/증거로 매핑합니다.
7. 권한 추가, RBAC 확대, 쓰기 활성화, WAF 변경 전에 별도 승인을 요구합니다.
